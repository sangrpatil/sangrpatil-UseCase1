Business Question: Which is the best selling product?

📊 Approach & Query

Query Code


-- Query 4: Top 10 products with clean aggregation by quantity and revenue
SELECT 
    product_name,
    UPPER(TRIM(category)) as category_clean,
    SUM(total_quantity_sold) as total_quantity,
    SUM(total_sales_amount) as total_revenue,
    COUNT(*) as num_transactions,
    ROUND(SUM(total_sales_amount) / SUM(total_quantity_sold), 2) as avg_price_per_unit,
    ROW_NUMBER() OVER (ORDER BY SUM(total_quantity_sold) DESC) as quantity_rank,
    ROW_NUMBER() OVER (ORDER BY SUM(total_sales_amount) DESC) as revenue_rank
FROM best_selling_product
GROUP BY product_name, UPPER(TRIM(category))
ORDER BY total_quantity DESC
LIMIT 10

Query Description

Aggregated sales data by product_name using SUM(total_quantity_sold) and SUM(total_sales_amount), then ranked by both quantity and revenue. Normalized category names to identify the true best seller across all variations in the data. Calculated average price per unit and transaction count to provide comprehensive performance metrics.
